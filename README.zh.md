# 钱来张姐 · dsh-qianlai

[English](README.md)

面向小企业的 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) 财务助手插件社区项目。

**当前阶段：仓库建设。** 本仓库提供社区说明和协作入口。**插件源码尚未导入，
暂不提供可运行版本、安装命令、发布包或演示。** 源码接入与可用版本验证是后续独立工作。

## 如何参与

- [报告故障、提出建议或使用求助](https://github.com/qianlai-ai/dsh-qianlai/issues/new/choose)。
- [讨论想法、提问和分享案例](https://github.com/qianlai-ai/dsh-qianlai/discussions)。
- 通过 PR 改进文档与双语表达，先阅读[贡献指南](CONTRIBUTING.md)。
- 查看[路线图](ROADMAP.md)、[支持说明](SUPPORT.md)和[问题记录格式](docs/issue-reporting.md)。
- 安全漏洞走[私密安全报告](SECURITY.md)，社区行为问题走[行为规范](CODE_OF_CONDUCT.md)。

中文、英文均可。请只提供虚构案例，不要上传 API key、带 token 的 URL、
微信凭据、真实税号或银行卡号、未脱敏票据、账本数据库或私人聊天记录。

## 项目与维护

项目方向包括读票、银行流水导入、记账和会计复核辅助；这些是项目定位，
不表示本仓库现已交付或验证这些功能。项目不能替代会计，不提供税务申报或付款执行服务。

仓库归属 `qianlai-ai`，初期由 [@peyton-v5](https://github.com/peyton-v5) 维护，
职责见[维护者说明](MAINTAINERS.md)。

本项目由社区独立维护，是第三方插件；不代表 DeepSeek 官方出品、认证、合作或背书。
