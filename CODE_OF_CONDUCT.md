# 社区行为规范 / Code of Conduct

本规范适用于本仓库的 Issues、PR、Discussions 和评论，负责人是
[@peyton-v5](https://github.com/peyton-v5)。

尊重不同背景与经验的参与者。讨论针对问题和证据，耐心帮助初学者，
尊重贡献署名与隐私。禁止骚扰、威胁、歧视、辱骂、冒充他人、泄露私人信息、
恶意刷屏或报复举报者。

## 私密举报与处理

对仓库中的不当内容，在对应 Issue、PR 或评论的菜单选择
**Report content → Report to repository admins**。
本仓库已允许所有 GitHub 用户向管理员举报；报告不会成为公开 Issue。
提供相关链接和必要背景，不要公开复述隐私信息。

若没有管理员选项、涉及平台规则或维护者本人，选择 **Report abuse to GitHub Support**，
或按 [GitHub 举报说明](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
联系 GitHub。该渠道由 GitHub 处理，不是项目维护者邮箱。

维护者核对上下文后可采取提醒、隐藏违规内容、锁定争执讨论或限制参与等相称措施。
尽量保护举报者身份，仅向必要处理人员分享信息。有利益冲突的维护者应回避，
由组织其他管理员或 GitHub 处理。不承诺固定处理期限，尚无项目专属的站外私密联系渠道。
技术漏洞使用 [SECURITY](SECURITY.md)，不要把社区冲突当成漏洞。

## English

This policy covers this repository's issues, PRs, discussions and comments.
The responsible maintainer is @peyton-v5. Be respectful, focus on evidence, help
newcomers and respect privacy and attribution. Harassment, threats, discrimination,
insults, impersonation, disclosure of private information, spam and retaliation are unacceptable.

Use **Report content → Report to repository admins** on the relevant issue, PR or
comment to report privately. Reporting is enabled for all GitHub users. Include
links and necessary context without repeating private information publicly.
If unavailable, platform rules are involved, or the maintainer is the subject,
use **Report abuse to GitHub Support** as described in the linked guide; GitHub
handles that route independently.

Maintainers assess context and may warn, hide harmful content, lock discussions or
restrict participation proportionately. They aim to protect reporter identities
and share details only as needed. Conflicted maintainers should recuse themselves
in favor of another organization administrator or GitHub. No fixed response time
is promised. There is no project-specific private contact outside GitHub yet.
Use SECURITY.md for vulnerabilities, not general conduct concerns.
