# 安全报告 / Security reporting

## 当前范围 / Scope

本仓库处于建仓阶段，尚无插件源码、安装包或发布版本。
受理本仓库公开内容相关的安全报告；没有已验证的产品版本支持矩阵。

This repository contains community materials only. No plugin source, packages or
releases are provided. Reports concerning this repository are welcome; no
runtime security validation or product-version support matrix is claimed.

## 私密报告 / Report privately

使用 [Report a vulnerability](https://github.com/qianlai-ai/dsh-qianlai/security/advisories/new)。
私密漏洞报告已开启，初期接收人为仓库管理员 [@peyton-v5](https://github.com/peyton-v5)。

说明受影响的内容或提交、影响、最小复现步骤和合成案例。
不要放入真实密钥、登录凭据或账本；不要通过公开 Issue、PR 或 Discussion 披露漏洞细节。
已泄露凭据应先撤销或轮换，不要复制到报告。维护者核对范围并协调处理和披露，
不承诺固定回复或修复期限。

Use the private link above, monitored by @peyton-v5. Include affected content or
commit, impact and minimal reproduction using synthetic data. Do not include live
secrets or private ledgers or disclose details publicly. Revoke exposed credentials
first. Maintainers assess and coordinate handling and disclosure, without fixed deadlines.

一般求助见 [SUPPORT](SUPPORT.md)，社区冲突见[行为规范](CODE_OF_CONDUCT.md)；
不要把一般行为问题作为漏洞提交。 Use the support and conduct channels for non-security matters.
