## [0.1.0] - 未发布

第一个公开版本，适配 DeepSeek Harness `>=0.2.1-0 <0.3.0-0`。

### 新增

- 「钱来张姐」模式：DSH 模式下拉里多一项，选中后界面换成钱来绿配色，会话标题旁显示张姐头像，插件页图标也是她的头像。
- 本机一本账：一台电脑一家公司，SQLite 文件放在 `$DSH_HOME/moneycome/book.sqlite`，金额按分存整数。第一次启动自带一本虚构企业的样本账。
- 期初余额：按科目录建账那个月月初的余额，借贷必须相平；建账月份结账后不能再改。
- 读票：核价税合计、大小写金额、税率、号码位数、抬头，判断买方卖方，同一张票不记两次；结果里提醒核票不等于验真，附国家税务总局查验平台地址。
- 导入银行流水：CSV、TSV、TXT（含 GBK 编码）和截图。导入前自查余额连续、重复行、日期区间、原件印的期初期末与合计，任何一项不过整份不进账。同一账户同一段日期不能导两次；新卡与已有卡尾号相同时先问清，必要时改用更多位卡号区分。
- 记账：按随插件发行的会计包（小企业会计准则 · 小规模纳税人）推分录，先试推给老板看，同意后再记；记过的钱，流水来了只挂上去。
- 作废凭证、补挂凭据。
- 查余额、查利润（当月与当年累计）。
- 报表：某月末的资产负债表（简表）和利润表。
- 复核包：把某个月的报表、凭证、科目余额、流水、发票、待处理事项导出成 CSV，交给会计复核。以 = + - @ 开头的文字前加单引号，Excel 打开时不当公式执行。
- 办税提醒：按会计包期限表提醒结账与报税截止日，10 天内到期的事在账本现状里提醒；季度申报准备单汇总账上收入与销项发票，供会计核对，不算税。
- 结账后更正：已结账月份的凭证可在没结账的月份冲销，再带 `correctsVoucherNo` 记更正后的一笔。
- 结账检查七项：流水交齐、每笔流水记了账、凭据齐、借贷平、月末事项做了、上月已结账、账上银行存款和流水余额对得上。全过才能结账，结账时做损益结转并锁住这个月。
- 微信通道（`MONEYCOME_WECHAT=1`）：扫码登录，扫码的微信就是老板；文字、语音（用微信转好的文字）、发票照片、流水文件都能交给张姐，张姐每说完一轮把最后那段话发回微信。登录过期重新扫码，老板和对话接着用。
- 工具入口：参数类型不对时返回拒绝并指出字段；每次调用在一个写事务里执行，出错整笔回滚；同一本账被几个 DSH 进程同时打开时写操作排队。
- 真模型场景测试 `packages/dsh-qianlai/e2e/`，会调用 DeepSeek，不进 CI。
